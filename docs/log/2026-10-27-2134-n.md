## 1. Konteks Masalah (Audit Temuan K7)

Pada berkas `backend/services/annotator.py` baris 51–65, label data `label_kepercayaan` dan `aspek_komunikasi` di-generate secara otomatis menggunakan formula aturan heuristik kata kunci + rating bintang ulasan:
- Kata kunci low trust: `["palsu", "meragukan", "tidak ada", "kecewa", "bruntusan", "penyok", "ragu", "overclaim", "lama"]`
- Kata kunci high trust: `["resmi", "mantap", "puas", "terdaftar", "cocok", "bagus", "cepat", "ramah", "aman"]`
- Rating <= 2 memicu `Low_Trust`, rating == 3 memicu `Neutral`, rating >= 4 memicu `High_Trust`.

**Masalah & Risiko Akademis (Skripsi):**
Jika dalam penulisan skripsi atau dokumentasi dinyatakan bahwa model IndoBERT dilatih pada data berlabel manusia (*human ground truth*), ini merupakan ketidaksesuaian fakta ilmiah. IndoBERT pada dasarnya akan belajar meniru aturan kata kunci dan rating tersebut.

## 2. Opsi yang Diajukan & Keputusan User

Tiga opsi metodologis diajukan kepada user:
1. **Opsi A (Recommended) - Weak Supervision / Distant Supervision**:
   - Mempertahankan label aturan leksikon + rating saat ini untuk seluruh 8.365 ulasan.
   - Diakui secara jujur, transparan, dan metodologis di Bab 3 (Metodologi Penelitian) dan Bab 4 (Hasil & Pembahasan) skripsi sebagai *Rule-Based Weak Supervision* / *Distant Supervision*.
   - Tidak memerlukan waktu tambahan untuk anotasi manual ulasan per ulasan.
2. **Opsi B - Hybrid Gold Test Set**:
   - Data train/val menggunakan Weak Supervision, namun 200–300 ulasan pada test set dianotasi manual oleh manusia dengan skor Cohen's Kappa (*Inter-Annotator Agreement*).
3. **Opsi C - Rating Murni Konsumen**:
   - Hanya menggunakan rating bintang 1–5 asli dari ulasan Female Daily tanpa leksikon kata kunci kita sendiri.

**Hasil Keputusan User:**
User memilih **Opsi A (Weak Supervision / Distant Supervision)**.
