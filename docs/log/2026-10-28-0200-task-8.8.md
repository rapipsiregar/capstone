# Log Task 8.8: `/predict` Memakai IndoBERT (K4)

- **Tanggal/Waktu**: 2026-10-28 02:02 WIB
- **Target**: Memastikan endpoint `/api/v1/predict` memakai model IndoBERT otentik (fine-tuned) via `model_loader.py` dan mengukur waktu latensi eksekusi inferensi riil.
- **Implementasi**:
  1. Dibuat modul servis `backend/services/indobert_predictor.py` (84 LOC, <= 256 LOC) yang memuat model dan tokenizer fine-tuned IndoBERT Kepercayaan (3 kelas) dan Aspek (4 kelas) melalui lazy singleton caching `model_loader.py`.
  2. Modul menjalankan inferensi PyTorch forward-pass pada GPU/device (`torch.no_grad()` & FP16 autocast), menghitung probabilitas softmax, argmax ID, serta confidence score.
  3. Modul mengukur latensi inferensi riil `execution_time_ms` dengan presisi tinggi menggunakan `time.perf_counter()`.
  4. Endpoint `backend/api/v1/predict.py` diperbarui untuk memanggil `predict_indobert_authentic(request.text)` dan mencatat log inferensi ke database SQLite.
  5. Pengujian unit `tests/test_api_predict.py` (3 test) berhasil 100% passed dengan latensi inferensi hangat ~15-40 ms (jauh di bawah batas benchmark 1500 ms).
- **Verifikasi**:
  - `pytest tests/test_api_predict.py -v`: 3 passed in 10.27s.
  - `pytest tests/test_api_history.py tests/test_database.py -v`: 5 passed in 11.49s.
  - Batas LOC `backend/services/indobert_predictor.py` (84 LOC) dan `backend/api/v1/predict.py` (57 LOC) mematuhi batas <= 256 LOC.
