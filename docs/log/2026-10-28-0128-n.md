## 2. Bukti Empiris Kriteria Selesai (DoD)

### A. Pemuatan Model dari Path Konfigurasi
- Nilai default path dibaca dari `.env` / environment variable:
  - `INDOBERT_TRUST_MODEL_PATH=models/indobert_trust`
  - `INDOBERT_ASPECT_MODEL_PATH=models/indobert_aspect`
  - `TORCH_DEVICE=cuda` (atau `cpu` fallback)
- Model dimuat langsung ke mode evaluasi (`model.eval()`) dengan label mapping yang sesuai.

### B. Pesan Error Jelas & Informatif
Saat path model lokal tidak ada, modul membangkitkan `FileNotFoundError` spesifik:
```text
FileNotFoundError: IndoBERT model weights not found at 'models/non_existent_model_checkpoint'. Please verify the directory exists or check your .env configuration.
```

### C. Singleton Caching
Pemanggilan berulang `get_trust_model()` dan `get_aspect_model()` mengembalikan objek instans memori yang sama persis (`assertIs(model1, model2)`), mencegah redundansi alokasi memori VRAM GPU.
