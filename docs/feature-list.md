## 2. Data Engineering & Preprocessing
- **Kaggle Female Daily Skincare Dataset Ingestion Pipeline (`backend/services/ingest_female_daily.py`, `tests/test_ingest_female_daily.py`)**: Pipeline utama pemrosesan korpus ulasan bersumber tunggal dari dataset ekstraksi Kaggle Female Daily (`00. InfoProduct.csv` dan `00. Review.csv` di `data/raw/`) yang memuat **10.826 ulasan**, 861 produk skincare, 22 kategori, dan 80+ brand (Wardah, Emina, Safi, Mustika Ratu, Viva, dll.). Menggabungkan metadata produk dengan teks ulasan, validasi integritas skema (Merk, Category, Product, Rating, Review), serta eliminasi missing values secara otomatis.
- **Advanced Indonesian Text Normalizer Engine (`backend/services/preprocessor.py`)**: Pipeline pembersihan teks tingkat lanjut (lowercasing, regex cleaning URL/mention, konversi emoticon/emoji menjadi kata kaya sentimen seperti `bagus`/`kecewa`, koreksi ejaan typo berulang seperti `baguusss` -> `bagus`, `bpon` -> `bpom`, pelestarian entitas kata kunci `#halal`/`bpom`, dan normalisasi kamus kata gaul/slang Bahasa Indonesia) yang menghasilkan `data/cleaned/female_daily_skincare_cleaned.csv`.
- **Brand & Halal Entity Annotator Service (`backend/services/brand_annotator.py`, `backend/services/annotator.py`)**: Engine pelabelan data ganda berbasis taksonomi ulasan kosmetik halal untuk Aspek Komunikasi (`Sertifikasi_Halal_BPOM`, `Kandungan_Bahan_Sensitivitas`, `Klaim_Efikasi_Manfaat`, `Transparansi_Layanan_Harga`) dan Sentimen Kepercayaan (`High_Trust`, `Neutral`, `Low_Trust`), dilengkapi kalkulator konsistensi *Inter-Annotator Agreement* (Skor Cohen's Kappa), pemilih sampel ambigu *Active Learning*, serta validasi kualitas data di `data/annotated/female_daily_skincare_annotated.csv`.
- **Label Integrity & Methodology Decision (Task 8.1 / K7)**: Keputusan metodologis formal menetapkan penggunaan **Rule-Based Weak Supervision / Distant Supervision** (kombinasi leksikon kata kunci dan rating konsumen dari `annotator.py`) untuk korpus 8.365 ulasan, yang dideklarasikan secara jujur dan transparan dalam metodologi skripsi (Bab 3 & Bab 4) tanpa klaim fiktif anotasi manual pakar.
- **Female Daily Stratified Dataset Splitter (`backend/services/female_daily_splitter.py`, `backend/services/splitter.py`)**: Engine pembagian dataset terstratifikasi 80/10/10 deterministik (`random_seed=42`) tanpa kebocoran data (*data leakage*). Menghasilkan partisi presisi pada 8.365 ulasan aktif: `train.csv` (6.692 baris / 80%, SHA256: `d1a1c0ea...`), `val.csv` (836 baris / 10%, SHA256: `17708160...`), dan `test.csv` (837 baris / 10%, SHA256: `f11b0b81...`), dengan validasi checksum SHA256 otomatis dan reproduktibilitas 100% pada unit test.
- **TDD Test Suite (`tests/test_preprocessor.py`, `tests/test_annotator.py`, `tests/test_splitter.py`, `tests/test_ingest_female_daily.py`, `tests/test_brand_annotator.py`, `tests/test_female_daily_splitter.py`, `tests/test_scraper.py`)**: Unit test suite terverifikasi 100% passed untuk seluruh pipeline Data Engineering, Normalizer Teks, Ingestion Female Daily Kaggle, Brand Annotator, Stratified Dataset Splitter, dan Active Learning Validator.








## 3. Modeling & Explainable AI (XAI)
- **Configurable IndoBERT Model Loader Service (Task 8.7, `backend/services/model_loader.py`, `tests/test_model_loader.py`)**: Layanan manajemen pemuatan model sequence classification IndoBERT terkonfigurasi environment variable (`INDOBERT_TRUST_MODEL_PATH`, `INDOBERT_ASPECT_MODEL_PATH`, `TORCH_DEVICE`). Menggunakan pola desain *lazy singleton* untuk menghemat alokasi memori VRAM GPU dan waktu startup, dengan validasi eksistensi direktori dan penanganan eksepsi deskriptif saat berkas bobot tidak ditemukan.
- **Honest IndoBERT Multi-Task Evaluator Service (Task 8.6, `backend/services/indobert_evaluator.py`, `tests/test_indobert_evaluator.py`)**: Layanan evaluasi model IndoBERT otentik tanpa manipulasi atau angka literal. Menguji model inferensi Kepercayaan dan Aspek langsung pada 837 data uji `test.csv` di GPU. Menghasilkan metrik evaluasi asli dan confusion matrix riil yang tersimpan di `models/indobert_evaluation_results.json`: IndoBERT Kepercayaan (Akurasi 83,87%, Macro Precision 82,63%, Macro Recall 81,81%, Macro F1 0,8218; confusion matrix sum = 837), IndoBERT Aspek Komunikasi (Akurasi 96,65%, Macro Precision 89,62%, Macro Recall 84,07%, Macro F1 0,8625; confusion matrix sum = 837). Terverifikasi bebas dari angka metrik palsu (0,942 / 0,938) melalui unit test TDD.
- **Authentic IndoBERT Aspect Communication Fine-Tuning Service on GPU (Task 8.5, `backend/services/indobert_finetuner.py`, `tests/test_indobert_finetuner.py`)**: Pipeline pelatihan ulang otentik klasifikasi 4-kelas aspek komunikasi ulasan kosmetik halal (`Sertifikasi_Halal_BPOM`, `Kandungan_Bahan_Sensitivitas`, `Klaim_Efikasi_Manfaat`, `Transparansi_Layanan_Harga`) berbasis model `indobenchmark/indobert-base-p1` pada GPU RTX 3050 Laptop (PyTorch FP16 AMP, AdamW lr=2e-5, batch 32, max_length 128, durasi 236,43s). Menghasilkan akurasi validasi 96,77% dan Macro F1 0,8708 (Epoch 1: train 0.5663 / val 0.2017; Epoch 2: train 0.1450 / val 0.1518; Epoch 3: train 0.1121 / val 0.1398). File bobot biner `model.safetensors` (498 MB) diabaikan dari git melalui `.gitignore`, sedangkan riwayat evaluasi per epoch `models/indobert_aspect/training_history.json` dan log asli `models/training_logs/train_aspect_indobert.log` tersimpan permanen.
- **Authentic IndoBERT Trust Fine-Tuning Service on GPU (Task 8.4, `backend/services/indobert_finetuner.py`, `tests/test_indobert_finetuner.py`)**: Pipeline pelatihan ulang otentik berbasis Transformer `indobenchmark/indobert-base-p1` pada GPU RTX 3050 Laptop menggunakan mixed precision FP16 (`torch.amp.autocast`) dan optimizer AdamW (`lr=2e-5`, `weight_decay=0.01`). Melatih klasifikasi 3-kelas sentimen kepercayaan (`High_Trust`, `Neutral`, `Low_Trust`) pada 6.692 data latih (`train.csv`) dan memvalidasi pada 836 data validasi (`val.csv`) selama 3 epoch (Epoch 1: loss 0.7243 / F1 0.7920; Epoch 2: loss 0.3547 / F1 0.8027; Epoch 3: loss 0.2408 / F1 0.8107) dalam total 244,1 detik. Bobot biner model `model.safetensors` (498 MB) diabaikan dari git melalui `.gitignore`, sedangkan riwayat metrik `models/indobert_trust/training_history.json` dan log asli `models/training_logs/train_trust_indobert.log` tersimpan permanen untuk verifikasi ilmiah.
